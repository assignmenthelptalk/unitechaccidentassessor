# Unitech Accident Assessor

Astro starter site for `unitechaccidentassessor.co.ke`, focused on valuation and accident assessment services in Kenya.

## Commands

```bash
npm install
npm run dev
```

## Notes

- The homepage is already tailored for Kenyan valuation services.
- Contact details are placeholders and should be replaced with the real business information.
- The next good step is adding an enquiry form and service detail pages.
